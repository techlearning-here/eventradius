## Image Optimization (Optional)

To resize and convert to WebP:

### Using ImageMagick (command line):
```bash
# Resize to 1200x630
convert input.jpg -resize 1200x630^ -gravity center -extent 1200x630 output.jpg

# Convert to WebP
cwebp -q 85 input.jpg -o output.webp
```

### Using Python:
```python
from PIL import Image

img = Image.open('input.jpg')
img = img.resize((1200, 630), Image.LANCZOS)
img.save('output.webp', 'WEBP', quality=85)
```

### Online Tools:
- https://squoosh.app (Google's image optimizer)
- https://convertio.co (format converter)
