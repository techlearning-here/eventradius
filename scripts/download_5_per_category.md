## Quick Commands (Optional)

After downloading, resize all images at once (requires ImageMagick):

```bash
# Resize all to 1200x630
cd frontend/public/cover-images
for dir in */; do
  for img in "$dir"*.jpg; do
    convert "$img" -resize 1200x630^ -gravity center -extent 1200x630 "${img%.jpg}.webp"
  done
done
```

Or use the Python script in this folder to auto-resize:
```bash
python download_cover_images.py --batch-download --no-optimize
# Then manually replace with your downloaded images
```
