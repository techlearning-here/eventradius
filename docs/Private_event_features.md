# Private Event Mode – Feature Breakdown

## 1. Event Privacy & Access

- *Private visibility toggle*  
  - Mark an event as “Private” so it does not appear in public search, feeds, or SEO.  
- *Invite‑only access*  
  - Only invited guests can view details or RSVP.  
- *Access via secure link*  
  - Hosts share a special link via WhatsApp, SMS, email, etc.  
- *Email / phone validation*  
  - Guests must confirm their invited email or phone before seeing full details.  
- *No-account guest access (low friction)*  
  - Guests can RSVP without creating a full user account.

## 2. Guest List & Household Management

- *Bulk guest import*  
  - Upload CSV/XLS with guest name, email, phone, family/household, notes.  
- *Household / family grouping*  
  - Group guests under families/parties instead of only individuals.  
- *Primary guest + linked members*  
  - One invite per household; primary guest submits responses for the family.  
- *Plus‑one / additional guests rules*  
  - Configure whether a guest can bring partner/kids/extra people.  
- *Guest tags & segments*  
  - Mark guests as “close family”, “friends”, “VIP”, “out of town”, etc.

## 3. RSVP & Response Collection

- *Standard RSVP states*  
  - Attending / Not attending / Maybe.  
- *Family attendance counts*  
  - Number of adults, number of kids, optional names of attendees.  
- *Conditional fields*  
  - Show extra questions only if “Attending” is selected or if kids > 0.  
- *Editable RSVPs*  
  - Guests can update their response until a host‑set deadline.  
- *RSVP deadline & reminders*  
  - Set close date and auto‑reminders to non‑responders.

## 4. Food, Dietary & Logistics

- *Meal preferences*  
  - Veg / Non‑veg / Vegan / Jain / Kids meal / Custom options.  
- *Dietary restrictions*  
  - Allergies, intolerances, religious restrictions (free‑text + presets).  
- *Per‑person meal selection*  
  - Choose a meal for each named attendee when needed.  
- *Accommodation needs*  
  - Yes/No + details for stay requirements.  
- *Transport needs*  
  - Pickup/drop required, route, time window.  
- *Special notes to host*  
  - Free‑text field for accessibility, elders, children, etc.

## 5. Multi‑Function / Multi‑Day Events

- *Sub‑events / functions*  
  - Create multiple linked functions (e.g., ceremony, reception, lunch).  
- *Function‑level RSVP*  
  - Guests choose which specific functions they will attend.  
- *Per‑function headcounts*  
  - Separate counts for each function (adults, kids, total).

## 6. Messaging & Invitations

- *Multi‑channel invite sending*  
  - Generate content shareable via WhatsApp, SMS, email.  
- *Personalized invite text*  
  - Use guest name/family name and unique RSVP link.  
- *Automated reminders*  
  - Nudge pending guests before RSVP deadline.  
- *Message templates*  
  - Pre‑written copy for weddings, birthdays, memorials, etc.

## 7. Organizer Planning Dashboard

- *Overview metrics*  
  - Invited / Confirmed / Declined / Pending.  
- *Family / household breakdown*  
  - View responses by family with adult/kid counts.  
- *Meal summary*  
  - Totals per meal type and list of allergies/restrictions.  
- *Function‑wise attendance*  
  - Headcount per sub‑event (ceremony, reception, etc.).  
- *Logistics summary*  
  - Accommodation + transport + special needs totals.  
- *Export & share*  
  - Export CSV/XLS for caterers, planners, and venue.

## 8. Day‑Of Operations (Nice‑to‑Have)

- *Guest check‑in*  
  - Mark guests/families as arrived (optionally via QR or search).  
- *Household check‑in mode*  
  - Check in all members of a family at once.  
- *Staff / helper role*  
  - Limited access accounts for volunteers or coordinators.

## 9. Configuration & Settings

- *Privacy defaults*  
  - Choose default visibility for new private events.  
- *Question templates*  
  - Save frequently used RSVP question sets per event type.  
- *Language & locale*  
  - Support for multiple languages (e.g., English + Indian languages) for forms and invites.  
- *Branding options*  
  - Event cover image, colors, host names, and venue details.

## 10. MVP Recommendation

For a first version, prioritize:

1. Private visibility + invite‑only access.  
2. Email/phone validation and low‑friction guest access.  
3. Household/family RSVP with adult/kid counts.  
4. Meal and dietary preference collection.  
5. WhatsApp/SMS/email sharing of invite link.  
6. Organizer dashboard with headcount + meal summary + export.
