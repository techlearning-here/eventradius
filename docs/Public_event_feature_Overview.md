# Public Event Mode

## What is it

Public Event Mode is the open event workflow inside EventRadius for events that are meant to be discovered, browsed, and attended by the wider public.  
These events can appear in public listings, category pages, search results, nearby recommendations, and personalized feeds.

Public events can include:

- Movie screenings
- Workshops and classes
- Food and drink events
- Fitness sessions
- Music and cultural events
- Networking meetups
- Community gatherings
- Kids and family activities
- Micro-events and pop-ups

## What problem are we solving

Many public events struggle with discoverability, attendance, and conversion.  
Organizers often create an event page, but still face problems such as:

- low visibility beyond their own audience
- empty seats or unused capacity
- weak local discovery
- poor timing of promotions
- difficulty matching the right audience to the right event
- limited insight into what price, format, or timing will perform better

For users, the problem is also clear:

- too many scattered sources for local events
- difficulty finding relevant things nearby
- limited personalization
- missing out on last-minute offers or under-the-radar local experiences

## How we solve it

EventRadius Public Event Mode helps organizers publish discoverable events and helps users find the right events near them.

The platform solves the problem through:

- public event listing pages
- location- and radius-based discovery
- category browsing
- personalized recommendations
- dynamic offers and smart pricing
- targeted alerts for nearby and time-sensitive events
- organizer tools for performance, attendance, and demand optimization

Instead of just hosting an event page, EventRadius acts like a local event demand engine.

## What users can do

- Discover public events happening nearby.
- Browse by category, location, date, and interest.
- View event details, pricing, availability, and offers.
- Save or follow events and organizers.
- Get alerts for matching events or price drops.
- Register or book seats for public events.
- Explore discounted last-minute events and local deals.

## What organizers get

- Public visibility in discovery feeds and search.
- Reach beyond their own follower list or contact database.
- Better local exposure for underfilled events.
- Support for time-sensitive offers and dynamic pricing.
- Audience matching based on location, timing, budget, and interest.
- Insights into demand, occupancy, and conversions.
- Tools to attract new attendees, not just manage existing ones.

## Why this matters

Public events succeed when the right people hear about them at the right time.  
Many organizers do not just need event setup tools — they need actual demand, attendance, and better fill rates.

EventRadius helps bridge that gap by connecting public events with nearby users who are likely to attend.

## How Public Event Mode is different from Private Event Mode

| Aspect | Public Event Mode | Private Event Mode |
|---|---|---|
| Visibility | Visible in public listings, search, feeds, and recommendations | Hidden from public discovery |
| Audience | Open to anyone who discovers and registers | Only invited guests |
| Main goal | Discovery, attendance, conversion, seat filling | Guest coordination, planning, privacy |
| Access | Public event page | Invite link + email/phone validation |
| Promotion | Public discovery, notifications, dynamic offers | Direct sharing through WhatsApp, SMS, email |
| RSVP style | Open registration / booking | Invite-only RSVP |
| Typical use cases | Workshops, shows, classes, screenings, meetups | Weddings, birthdays, memorials, family gatherings |
| Planning focus | Reach, occupancy, pricing, growth | Family count, meal planning, household coordination |
| Discovery engine | Core part of product | Not used |
| Privacy level | Public by design | Private by design |

## In simple terms

- *Public Event Mode* is for events you want people to discover.
- *Private Event Mode* is for events you want only invited people to access.

## In one sentence

Public Event Mode helps organizers attract and convert public attendees through discovery, personalization, and dynamic local demand, while Private Event Mode helps hosts manage invite-only events with privacy and structured planning.
