# EventRadius.ai Pricing Strategy

## Business Model Overview

**B2B2C Model**: Event discoverers (end users) are always FREE. Revenue comes from event organizers who pay for premium tools to create, manage, and monetize their events.

- **Discoverers/Users** = Free (always)
- **Organizers** = Paid tiers (Free/Starter/Pro/Enterprise)

## 💼 For Organizers (Revenue Model)

### 🆓 FREE TIER (For New Organizers)

**Price**: $0/month

| Feature | Limit |
|---------|-------|
| **Active Events** | 3 concurrent events max |
| **Event Creation** | Basic info, single image, standard approval |
| **Event Types** | Standard & Preview events |
| **Contact Info** | Email only (no phone in free tier) |
| **Analytics** | Basic view count only |
| **Approval** | Standard queue (48-72 hours) |
| **Support** | Community forum only |

**Free Tier Restrictions**:
- No dynamic pricing
- No real-time notifications
- No recurring events
- No CSV export
- Standard placement in discovery (no priority)
- Events auto-expire after 30 days

## 🎯 Why This Model Works

### Benefits of Free Discoverers

| Advantage | Impact |
|-----------|--------|
| **Large user base** | More value for organizers |
| **Network effect** | More events = more users = more events |
| **Word-of-mouth growth** | Attendees invite friends |
| **No barrier to entry** | Everyone can find events |

### Revenue from Organizers

| Organizer Type | Tier | Value Proposition |
|----------------|------|-------------------|
| Casual organizers | Free | Test platform, small events |
| Small businesses | Starter | Regular meetups, community events |
| Professional organizers | Pro | Monetize events, scale operations |
| Chains/Enterprises | Enterprise | AI optimization, integrations, ROI |

## 📈 Key Differentiators

### Unique Selling Points

1. **Dynamic Pricing for Local Events**
   - Unique feature for cinemas, fitness studios, restaurants
   - Yield management for perishable inventory (seats/slots)

2. **Real-time Notifications**
   - Proactive vs reactive
   - Push deals when users are nearby and free

3. **AI-Powered Insights (Enterprise)**
   - Predict attendance before publishing
   - Smart discount recommendations
   - Audience targeting optimization

4. **Perishable Inventory Focus**
   - Cinema seats, fitness classes, restaurant tables
   - Value drops to zero after time passes
   - Perfect for dynamic pricing
